Section 01

Introduction

⚠

India processed over 100 billion UPI transactions in 2023 — the world's largest real-time digital payment ecosystem (NPCI, 2024) — yet students have zero visibility into their own spending.

📱

SBI sends millions of SMS transaction alerts daily — unstructured, unanalyzed data sitting unused in inboxes, never aggregated into insights.

🤖

Large Language Models now enable context-aware financial coaching, Vision OCR receipt scanning, and zero-shot vendor classification — capabilities no existing student finance app uses.

📊

Existing apps (Walnut, CRED, MoneyView) require full bank account linkage, raising privacy concerns. Manual tracking is tedious — students abandon it within weeks.

🔍

SpendWise requires zero bank linkage — users paste SBI SMS or upload receipts. AI handles the rest: parsing, categorization, coaching, forecasting.

Outcomes of Literature Review
💡
SMS Parsing is Proven but Incomplete
Thakare (2023) and Johri (2023) confirm SMS-based parsing is a valid, privacy-respecting method for Indian users — but implementations remain Android-only and lack web deployability, AI coaching, or forecasting.
⚡
ML Categorization Fails on Unknown Vendors
Classical ML works for known merchants but fails silently for unknown vendors. No existing work uses zero-shot LLM classification with XAI reasoning for this fallback — a critical unaddressed gap.
🔍
LLMs Show Promise But Lack Grounding
de Zarzà et al. (2024) demonstrates LLMs as financial advisors — but with generic advice. No work grounds coaching in the user's actual historical UPI transaction data (context-augmented generation).
📊
Students Lack Financial Self-Awareness
Dev et al. (2024) empirically confirms UPI users — especially students — have poor financial self-awareness despite heavy digital payment usage, yet no tool addresses this in an account-linkage-free manner.

Section 03

Research Gaps & Contributions

Gaps identified in the literature review and how SpendWise directly addresses each one.

Gaps Found in Literature
1. Web-Based UPI Tracker Missing
All prior SMS-parsing work is Android-only. No web-based, production-deployed UPI tracker exists in academic literature.
2. No LLM Integration for Vendor Classification
Existing tools use keyword rules or classical ML. No prior work uses zero-shot LLM classification with confidence score and XAI reasoning for unknown vendors.
3. No Contextual AI Financial Coaching
Prior AI finance tools give generic advice. No system grounds coaching in the user's actual historical UPI spending data via context-augmented generation.
4. Receipt OCR Not Combined with SMS Pipeline
Receipt scanning and SMS parsing exist independently in literature; no system combines both input modalities into one unified tracker dashboard.
5. No Spend Forecasting for Indian UPI Students
General ML forecasting exists (WONGA, 2023) but no work applies Weighted Moving Average forecasting specifically to Indian UPI student spending patterns.
How SpendWise Addresses Them
✓
Full-Stack Web Deployment
Production-deployed on Vercel (frontend) + Render (backend) + Supabase PostgreSQL — works on any device with zero app install.
✓
Zero-Shot XAI Vendor Classifier
Groq LLaMA 3.3 classifies unknown vendors with confidence % + explainable reasoning displayed to the user. localStorage memory persists results.
✓
Context-Augmented AI Coach
LLaMA 3.3 receives the user's actual category-wise totals and transaction count — generating grounded, personalized financial insights, not generic tips.
✓
Unified SMS + Receipt Pipeline
LLaMA 4 Scout Vision OCR extracts vendor, amount, date, and category from photos — combined in the same dashboard as SMS parser, single unified tracker.
✓
WMA Forecast + Verdict System
Weighted Moving Average projects month-end spending with 🟢 On Track / 🟡 Careful / 🔴 High Spend verdict — lightweight, explainable, student-specific.

"SpendWise bridges the gap between automated UPI data collection and intelligent, explainable financial feedback — specifically designed for Indian college students."

Section 05

Objectives

O1
SMS Transaction Parsing
To parse SBI UPI SMS notifications across 2 distinct message formats using regex-based extraction and auto-categorize transactions into 10 spending categories using MERCHANT_MAP lookup and localStorage vendor memory.
O2
JWT Authentication + Secure RESTful API
To implement JWT authentication with Supabase Row-Level Security and a RESTful API covering transactions, budgets, and analytics endpoints with full CRUD and stats operations.
O3
Context-Augmented LLM Financial Coaching
To integrate Groq LLaMA 3.3-70B with user's actual spending context (category totals, transaction count) to generate personalized 5-card financial insights with staggered reveal animations.
O4
Vision LLM Receipt Scanner + Zero-Shot XAI Categorizer
To deploy LLaMA 4 Scout Vision for OCR receipt scanning and zero-shot LLM classification for unknown vendors — both with user confirmation workflow and XAI reasoning displayed alongside confidence %.
O5
Spend Forecasting + Analytics Dashboard
To implement a Weighted Moving Average forecast model with 🟢/🟡/🔴 verdict system, alongside Recharts-powered donut charts, weekly bar charts, dual-line forecast charts, and month-switcher analytics.

Section 06

Proposed Methodology

End-to-end system pipeline — from raw user input through AI processing to analytical output.

Step 1 · Parsing
SMS Regex Parser
Extracts merchant, amount, date from 2 SBI UPI formats. MERCHANT_MAP + localStorage for instant categorization.
Step 1B · Vision
Receipt OCR
LLaMA 4 Scout Vision extracts vendor, amount, date, category from uploaded receipt photos via drag-drop or camera.
Step 3 · AI Classify
Zero-Shot XAI
Unknown vendors → Groq LLaMA 3.3 zero-shot classification with confidence % + explainable reasoning shown to user.
Step 5 · Storage
Supabase + RLS
JWT Auth + Supabase Row-Level Security ensures each user sees only their own data. PostgreSQL via Supabase BaaS.
Step 6A · Forecast
WMA Model
Weighted Moving Average algorithm projects month-end spend. Recent days weighted higher. 🟢/🟡/🔴 verdict displayed.
Step 6B · Coach
AI Financial Coach
LLaMA 3.3 receives category-wise totals + transaction count to generate grounded, personalized 5-card financial insights.
